    Environments Hubid → module → Taskset

    This is verifiers' own rule: drop the owner and the version, swap - for _, import that module, and take the class it lists in __all__. Try a different id.

    Three pieceswhat each one is
    verifiersThe framework. Defines TaskData, Task, Taskset, toolsets and judges, then runs an agent on a task and records a trace. This page follows one of its rollouts.
    prime-envsPrime Intellect's repo of first-party environments. It sets the conventions this package follows, checked near the end of the page.
    HubThe registry. A package published with prime env push installs by id, and the id resolves exactly as shown on the left.
    package › convomem_arena/

    A taskset is a package

    Each file maps to one verifiers base class. Data is frozen, behaviour lives on the task, and tools run as their own MCP server.

    load › Taskset.load() › mix()

    One fact, buried on purpose

    What load() does. It yields tasks lazily. For each ConvoMem item it keeps every evidence conversation, samples filler conversations from the same persona, and places the evidence at seeded random positions in its original order.

    The question, gold answer and evidence positions go on TaskData. Only prompt reaches the model. The rest stays on the evaluator for scoring.
